# Public experiment assets

- `gsm8k_split.json`: exact pre-encoded reference split, 1024 training/64 development/64 official-test examples. Question identifiers are SHA256 hashes of question text. The split is not private user data; it derives from the MIT-licensed GSM8K dataset.
- `evaluation-prompts.json`: complete 152-item source prompt bank. The screenshot pilot selects16 general+12 math+4 requested-repeat tasks, not the whole bank.
- `LICENSE.gsm8k`: retained dataset MIT notice.
- `projection.pt`: generated by `python prepare_assets.py`; not committed. Exact random projection seed501, shape3584×128, tensor SHA recorded in `PROVENANCE.json`.

The raw source order matters for the seeded shuffle. The original split records hashes of the raw `train.jsonl` and `gsm8k_test.jsonl` files. For a byte-exact rebuild, use those files and the pinned Dream tokenizer; `prepare_assets.py --raw-train ... --raw-test ...` verifies both raw hashes and resulting records.

Canonical upstream raw data: <https://github.com/openai/grade-school-math/tree/master/grade_school_math/data>. Source-file names may differ; the rebuild command maps its test argument to the canonical key stored in the split.

Training/dev IDs are separate from test IDs; themes are not fully separated, and development includes a microscope theme also present in the pilot test. Do not present this split as a new blind evaluation.
