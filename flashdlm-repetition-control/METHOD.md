# 方法与截图版本的实现边界

输入为当前模型连续4个实际原生去噪输入。对每个输入重算Dense中间层隐藏状态，按Dream预测位置对齐，乘固定随机投影到128维并LayerNorm。

风险模块先映射到64维，在token轴使用3/5/7卷积核；拼接并融合后，再对每个位置沿去噪时间轴使用两层kernel3的因果卷积。最新空间特征、时间特征和MASK标记共129维，经MLP输出相邻token、短语、句子三个独立logit，经sigmoid得到风险分数。

风险标签来自自由生成文本中的启发式重复片段。仅当前仍被MASK且会在接下来至多4个外层步骤提交的位置参与预测损失。未来结果只用于标签，不作为风险头输入。

总损失为：

\[
L=L_{diff}+0.1L_{risk}+0.1g\,\mathrm{softplus}(z_{bad}-z_{AR}+0.5)
\]

其中风险BCE对正负类取均衡均值；`bad`是选中的重复片段边界token，`AR`是固定自回归模型给出的替代候选。权重 `g=0.25+0.75*max(risk)` 在输出约束中断梯度；风险BCE自身通过四帧特征同时更新CNN与LoRA。离散生成、候选选择和remask决策不求导。

LoRA只训练每层注意力q/k/v/o投影的rank8、alpha16适配器，基础权重冻结。AdamW lr2e-5，warmup8次更新，weight_decay0.01，梯度范数裁剪1。共96次更新；第0/32/64次更新前各生成16条轨迹。

推理流程：原生解码 → 规则提出重复候选 → 片段最大风险超过类型阈值 → 遮盖后出现的重复片段及其后缀 → Dream重新预测 → AR依据重建的左前缀评分 → 从top64中排除原边界token和不允许的特殊token，提交最高排名允许候选 → 重建Dream缓存并重置AR验证缓存。

EOS仅在AR原本top1时允许作为修复候选；每回答最多8次修复、同类型起点只尝试一次。不会通过删除输出字符串或强制截断来伪造改善。

本版本不要求修复token同时为Dream与AR的top1；Dream新预测只是被记录。其后提出的严格一致提交规则尚未计入截图结果。

基础扩散损失使用普通金标准GSM遮盖监督；自由轨迹风险/修复损失使用模型实际生成的前缀，二者不要混淆。固定投影不构成一个教师编码器；没有额外的教师语义特征对齐损失。
