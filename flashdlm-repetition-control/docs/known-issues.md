# 已知局限：复现时保留，不能隐藏

1. `repeats.py`是截图实验所用的启发式。英文段落含换行时，句子正则可能把整段吞成一句；正常升温/降温对照也可能被相似度误报。短语规则会误报正常强调。
2. 数字保护会漏掉异常的长数字串；关键词意图保护不能覆盖所有“输出N次/word exactly N times”的措辞。合法叠词、词边界和计数错误仍需人工判断。
3. 风险校准按单个位置，推理按片段最大分数；两者口径并不一致。截图版本阈值只扫0.3至0.9、步长0.1；无正例类别默认0.5，不代表验证有效。
4. 训练选定预测窗口正例很少；开发集的相邻/句子类别没有正例。dev和test含显微镜主题重叠；提示此前已经观察过，不是新盲测。
5. 连续输入来自原生缓存轨迹，但中间特征是Dense重算，额外计算明显且可能与原生缓存隐藏值不同。
6. AR替代候选不保证正确；原边界token被排除，故“token改变”是机械结果，不能当成语义修复成功。修复也可能引入新循环或损伤表达。
7. 原生基线首个AR不匹配位置仍提交Dream候选，底层快照保留此行为。仅修复分支显式提交AR选择。
8. 单种子、小预算、只有原始与完整两组。不能归因于单个CNN、loss或remask模块，也不能用微观候选数代替独立回答数。
9. 数学评分为答案抽取匹配（####、boxed优先），不是完整推理验证。自动重复计数不是人工循环标注。
10. 不支持从32/64步中间checkpoint精确恢复优化器；需要新目录重训。`--resume`只用于已经完成的阶段或评估续跑。

修复上述问题应建立新的实验版本并重新验证；不能将新算法的输出混称为原截图结果。
